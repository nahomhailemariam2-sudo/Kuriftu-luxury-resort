KURIFTU RESORTS — Premium Website Concept

A premium, responsive website concept created for Kuriftu Resorts.

The design focuses on luxury hospitality, Ethiopian destinations, wellness, adventure, dining, accommodation, photography, guest experiences, and modern interactive features.

---

✨ Features

- Full-screen luxury hero slideshow
- Automatic slide transitions
- Keyboard controls for hero slides
- Responsive navigation
- Mobile hamburger menu
- Smooth scrolling
- Scroll-reveal animations
- Destination showcase
- Resort experiences section
- Rooms and suites section
- Wellness section
- Achievements / journey timeline
- Staff and hospitality section
- Guest review carousel
- Interactive photo gallery
- Full-screen image lightbox
- Back-to-top button
- Responsive mobile/tablet/desktop layout
- Luxury typography and visual styling
- No external JavaScript libraries required

🚀 How to Use

1. Download or clone the project

Place all files in one project folder.

2. Add the images

Put the approved resort photography into the appropriate "assets" folders.

The filenames must match the filenames used by "index.html".

For example:

assets/hero/hero-1.jpg

and:

assets/branches/bishoftu.jpg

3. Open the website

Open:

index.html

in a modern web browser.

No server or installation is required for the basic website.

🌐 Publishing on GitHub Pages

Step 1

Create a new GitHub repository.

Example:

kuriftu-premium

Step 2

Upload:

index.html
style.css
script.js
README.md
assets/

Step 3

Open the repository's:

Settings

Then:

Pages

Step 4

Under deployment settings, select:

Deploy from a branch

Choose:

main

and:

/ (root)

Then save.

GitHub will generate a public website address.
